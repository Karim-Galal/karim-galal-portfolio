## Architecture

The project follows a modular React architecture separating application configuration, pages, sections, reusable components, and portfolio data.

```text
src/
├── app/
│   ├── config/
│   └── router/
│
├── pages/
│
├── sections/
│   ├── hero/
│   ├── about/
│   ├── skills/
│   ├── projects/
│   └── contact/
│
├── shared/
│   ├── components/
│   └── hooks/
│
├── data/
├── layouts/
├── styles/
├── assets/
│
├── App.jsx
└── main.jsx
```
